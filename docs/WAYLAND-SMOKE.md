# Wayland smoke recipe (sandbox, headless Weston 9, NOT a real desktop)
Found feasible at 7:53 on 2026-11-26: weston 9.0.0 (Ubuntu jammy debs) extracted to /tmp/wl/root. Module directories are hard-coded to /usr/lib, so the strings in weston, libweston-9.so and libexec_weston.so were patched (same length, NUL padded) to /tmp/lw9 and /tmp/lw9w, which are symlinks to the extracted module dirs. Run `weston --backend=headless-backend.so --shell=kiosk-shell.so --use-pixman --socket=wl-test`.
Result with the CURRENT build (sctk 0.19, release): Pawline connects, creates its surface and redraws on Wayland (4 PERF redraws of ~5 ms in 5 s, process alive). Kiosk shell + pixman, no layer-shell global from weston.
Limits: weston 9 has no virtual-keyboard or test-input protocol, so key and pointer INPUT cannot be injected; this verifies startup, surface creation and drawing only. Not KDE, niri, sway, real GPU, real input, fractional scale or multi-monitor. Background processes die at the end of each tool call, so the script starts weston and the app inside one run.
