## Sway pointer, clipboard and wheel smoke (8:08), baseline db2f3ae vs migrated b9198e3, both release builds
Tool: tools/vptr (scratch, NOT part of the workspace; build it with its own cargo run) is a ~40-line zwlr_virtual_pointer_v1 client for click and wheel. Scripts: tools/sway_ptr.sh, tools/sway_wheel.sh (sandbox paths).
- Pointer click: a click on the gear opens Settings on BOTH builds, screenshots pixel-identical in layout (/tmp/swp_base.png, /tmp/swp_mig.png).
- Clipboard: after one key press (needed for a keyboard serial) a click on a reply bubble puts the exact text on the Wayland clipboard (read back with wl-paste) on BOTH builds. Without a prior key press, nothing was copied on either build (no serial yet); same on both, so not a migration difference, but a real-use caveat: the first click before any key press may not copy on Wayland.
- Wheel (discrete axis) over a long Arabic/English history scrolls the chat on BOTH builds; the post-scroll screenshots are byte-identical between builds.
- Still unverified: held-key repeat (the new repeat_key handler), drag to move the orb, data-device paste INTO Pawline, KDE, niri, GPU, fractional scale, multi-monitor. Single sandbox compositor, one run each, author-written.
